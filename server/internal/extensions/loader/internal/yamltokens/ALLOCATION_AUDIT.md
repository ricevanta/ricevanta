# Parser allocation source audit

The candidate reserves cumulative allocation before every reachable growth operation. `Budget.Reserve` enforces 67,108,864 bytes and 1,000,000 objects without refunds. Native stack measurements and independent source review remain Gate A requirements. This audit supplies source bounds for review, not approval.

## Charge rule

`allocation` first rejects logical bytes above 67,108,864 or objects above 1,000,000. Those checks bound multiplication and addition before `Reserve`: `2*bytes + 32*objects` cannot overflow `uint64`. A single allocation of at least 32,768 logical bytes instead reserves `bytes + 8,192`. Every other family uses the first rule, including several helper objects charged together. `Reserve` checks each request against the remaining counter before changing either counter; failure changes neither counter.

Go 1.27.1's `runtime/msize.go:16-40`, `runtime/malloc.go:1119-1155` and `internal/runtime/gc/sizeclasses.go` establish small size classes, pointer headers and 8 KiB large pages. Each small object, including its pointer header, fits `2*logical size + 32`. Each large object fits `logical size + 8,192`, which also fits the general rule. A zero-size reservation may overcharge. Tiny allocator packing cannot exceed the charged object count. Native target pointers are 64 bits; Node and pointer charges use `unsafe.Sizeof`, rather than a hard-coded Linux layout.

The initial reservation is 8,192 logical bytes and eight objects, charged as 16,640 bytes. `begin` executes once, before even global length/UTF-8 rejection. It covers ledger/statistics descriptors, parser/builder escape storage and fixed helper/defer overhead. Linux layouts on Go 1.27.1 amd64, as `TestParserLayouts` reports, are: parser 2,432, builder 2,456, Budget 64, statistics 72 and event 272 bytes. The two parser/builder instances plus ledger and statistics occupy 5,024 logical bytes and four potential heap objects. Event values and nonescaping callback/defer state have bounded lexical lifetimes. No callback or closure escapes the call. Eight objects and 8 KiB leave a reserve for fixed compiler helper storage. Compiler escape behavior and this fixed reserve must receive independent review on the exact toolchain; finite deltas do not replace that review.

## Reachable allocation families

Let B = 1,048,576 payload/value bytes, E = 262,208 emitted tokens, S = 64 scanner/parser stack entries, N = checked tree nodes at most 65,536, and D = 16 container depth.

| Family | Source bound and reservation |
|---|---|
| Ledger entry | `begin` reserves the fixed allowance once. Preflight and construction share the same Budget. A standalone Node measurement calls `begin` on its fresh ledger. |
| Reader | `yaml_parser_initialize` reserves both fixed reader arrays before either make. `readerc.go` only reslices those arrays; lookahead checks their capacities. Reader arrays are recreated for the second pass and charged again. |
| Scalar/temporary bytes | `appendBytes` checks B before growth; `appendValue`, `readValue` and `readLineValue` check remaining aggregate value bytes first. Growth reserves the full new capacity, including abandoned arrays. A failed reservation leaves length/capacity unchanged. |
| Scratch reuse | Three whitespace/break buffers retain capacity across scalar scans within a pass. Reuse makes no reservation and no refund. Scalar value buffers remain separately owned until their queued token is consumed. |
| Geometric/clamped growth | Byte growth starts at 32, doubles existing capacity, raises to the requested length if needed, and clamps at B. Typed storage other than tokens starts at 16 and clamps at its family cap. Tokens preserve pinned append growth. Each actual backing allocation receives its own charge. A final clamp is a separate allocation; no less-than-twice-capacity claim is used. |
| Tokens | Insertion checks E and aggregate value bytes before queue growth. Consumed slots are compacted before growing a full queue. Before pinned append growth, reserve `max(1, 2*capacity) * sizeof(token)` with allocator rounding. Go 1.27.1 runtime slice growth requests at most that doubling bound; the charge also covers size-class rounding. Pinned capacities preserve token-pointer behavior across lookahead compaction. At most E tokens enter the queue; backing capacity is bounded by the rounded doubling charge for E slots. |
| Simple keys | At most S live slots, keyed by flow level. Token lookup searches those slots. No map allocation or retained stale-key map entry exists. Push reserves its backing slice before growth. |
| Indents/states/marks | Every push checks S and routes growth through `boundedAppend`. Complete backing capacities are charged, including each abandoned array. Fixed preflight parent indices occupy 16 stack entries. |
| Comments | The scanner advances upstream lexical marks but never writes comment text. Presence flags preserve pinned comment splitting. A fixed 65-slot start-mark/presence summary and one end mark replace the comment queue. A gap resets the chain; each live indentation level retains its earliest matching start. Unrolling consults the latest end and its level summary. New indentation levels clear their slot. These fields live inside the parser and use the fixed entry allowance, without input-driven allocations. Event comment joins see nil fields and do not allocate. Node comment strings remain empty. Comments inside scalars follow scalar allocation rules. |
| Arity records | Preflight reserves one 65,536-element uint32 buffer before make, then limits its visible length/capacity to exact N. This is flat metadata, not a tree. Its 262,144 logical bytes remain charged after release. |
| Node arena | Reserve `(N+1)*sizeof(yaml.Node)` before one exact make. Construction checks N before each node write and D before descent. Arena capacity cannot grow. |
| Content arena | Reserve `N*sizeof(*yaml.Node)` before one exact make. One edge belongs to the document. Each container carves its exact preflight arity using a full slice expression. Empty containers retain nil Content. Construction checks remaining edges and final exact consumption. |
| Scalar strings | Reserve each scalar's value length and one object before byte-to-string conversion. Empty/single-byte runtime shortcuts may allocate less. Aggregate scalar bytes remain at most B in each pass. |
| Resolver underscores | `strings.ReplaceAll` runs only when underscores exist. Reserve the original input length and one object before calling it. Go `strings/strings.go:1136-1179` uses one Builder.Grow for the exact result size; `strings/builder.go` cannot grow again when that size is sufficient. Result length does not exceed input. |
| Resolver integers | `integer` and `negativeInteger` return tags using checked uint64 accumulation. They reproduce fixed-base/signed/unsigned/prefix/range behavior from Go 1.27.1 `internal/strconv/atoi.go`, after pinned underscore removal. No concatenation, NumError, boxing or parsed Go value is created. Differential tests include binary/octal fallback sign quirks and signed/unsigned endpoints. |
| Resolver floats | Before each `strconv.ParseFloat`, reserve `len(input)+48` logical bytes and two objects. Go `strconv/number.go:93-99,251-277` constructs at most one 48-byte NumError and one cloned input; `internal/stringslite/strings.go:115-123` bounds the clone. Internal atof/decimal arithmetic uses fixed local arrays and returns primitives/static errors. No decimal String, formatter, reflection or error-string call occurs. |
| Resolver timestamp/regexp | `timestamp` recognizes the four pinned formats, calendar validity, variable-width fields, repeated spaces, fraction digits and timezone ranges without time.Parse or time-zone state. `yamlFloat` recognizes the pinned anchored expression without regexp. Both scan bounded strings, use fixed locals and allocate nothing. Their equivalence needs independent review; ordinary differential tests provide finite evidence. |
| Errors | Static sentinels only. The first parser guard wins. Error paths use the same checked allocation helpers and return nil Node/Budget. No raw publisher diagnostic, formatted error or recovery allocation exists. |
| Directives/tags | Lexical dispatch rejects directives/anchors/aliases/tags before their fetch routines. Event directive processing performs no default-prefix copies or directive appends. Unreachable scanner property helpers still use bounded byte helpers; the candidate never calls them for signed input. |

All capacity multiplications use bounded integers: E times a fixed token size, S times a fixed stack size, B bytes, or N+1 times Node size. On all three required 64-bit targets these products fit both int and uint64. Public Reserve also rejects MaxUint64 byte/object requests without charging them.

## Recursion, agreement and limits

Construction has at most 16 container frames, one scalar frame and its caller/document frame. The scanner/event state machine uses bounded slices, not input-driven recursive descent. Scalar/helper loops cannot add recursion. The 8 MiB stack ceiling still requires native StackInuse evidence, including failures.

Both passes consume unchanged payload bytes. Preflight proves framing through stream end before any arena allocation. The second pass checks kind/arity/count/depth and requires exact arena consumption. The independent oracle runs before candidate Check/Decode and compares both acceptance directions, rejection class, complete Node fields and counts, omitting only presentation comments.

Mandatory maximum manifests, every other component branch at numeric/cardinality limits, the commented-empty-mapping counterexample and implicit-class capacity cases must succeed with normal budgets. Injected exhaustion is separate and tests every reached allocation ordinal in byte and object modes. Passing samples do not prove acceptance for every possible profile input. Native extended/timed-fuzz evidence and independent review of the allocation charges, fixed overhead, resolver equivalents and oracle rules remain required before Gate A approval.
